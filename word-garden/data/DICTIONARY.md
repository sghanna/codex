# Word Garden vocabulary and source

The 36 letter racks, puzzle titles, and required answer sets in `families.json` were selected for Word Garden. Their crossword positions are generated deterministically by `scripts/generate_puzzles.py`, checked for connected crossings and spacing, and committed as fixed `puzzles.js` data. No dictionary or generator runs on a player's device.

Optional bonus vocabulary starts with lowercase, plain alphabetic entries of three to six letters from the **English Speller Database (ESDB) American English Hunspell dictionary**, release `rel-2026.02.25` (`7e99eda`), size 60. The build script also expands the dictionary's own prefix and suffix rules, so ordinary plurals and inflections such as `CARS`, `CARES`, and `ACES` are considered. Source: <https://github.com/en-wl/wordlist/releases/tag/rel-2026.02.25>. The pinned `hunspell-en_US-2026.02.25.zip` has SHA-256 `ac8e73310e951d88c52c2cf2ba54ceaca34f8486a81630ac8a75dc5f931179f9`. Its copyright and permission notice is preserved in [ESDB-Copyright.txt](ESDB-Copyright.txt).

To favor familiar bonus words, `scripts/build_bonus_lexicon.py` keeps entries with an English frequency score of at least 3.0 from **wordfreq 3.1.1** and removes the explicit entries in `bonus-exclusions.txt`. All reviewed required words and the hand-authored entries in `bonus-additions.txt` are then included. The frequency measure is an editorial filter, not a claim that every accepted word will be familiar. The resulting subset is in `bonus-lexicon.txt`. The game uses only each puzzle's matching subset in `puzzles.js`; it makes no network or dictionary lookup while playing.

The bonus rule is consistent across the pack: a guess earns a bonus if it is present in the reviewed lexicon, can be made from that rack's physical tiles, and is not a required answer on that board. Guesses outside the defined list leave progress unchanged.

To regenerate the lexicon, install `wordfreq==3.1.1` in a development environment and run `python3 scripts/build_bonus_lexicon.py`. Then run `python3 scripts/generate_puzzles.py`; `python3 scripts/generate_puzzles.py --check` verifies the committed pack. This regeneration fetches the pinned ESDB release and checks its SHA-256. Normal puzzle generation and game use require no network or Python package.
