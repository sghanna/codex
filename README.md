# Codex games

[Play Hearts](https://sghanna.github.io/codex/hearts/)

The Hearts game is in `hearts/`. Its [README](hearts/README.md) covers gameplay, development, testing, and releases. GitHub Pages publishes the `main` branch from this repository’s root.

[Compare card-shading options](https://sghanna.github.io/codex/reviews/card-opacity/) — six black overlays, an interactive sample hand, and WCAG contrast measurements. This standalone review does not change the game or its saved progress.

[Compare three darker reds](https://sghanna.github.io/codex/reviews/red-ink/) — full-brightness and shaded samples, with the earlier 20% reference overlay.

[Compare six turn cues](https://sghanna.github.io/codex/reviews/turn-cues/) — replay six ways to make your turn obvious when every card is playable. The practice hands use separate saves and leave the game unchanged.

[Compare received-card reviews](https://sghanna.github.io/codex/reviews/received-cards/) — six ways to make the three cards passed to you obvious before play starts.

[Compare home-screen icons](https://sghanna.github.io/codex/reviews/home-icons/) — six designs at small and enlarged sizes. D, Gold seal, is selected.

[Compare heart and moon cues](https://sghanna.github.io/codex/reviews/heart-tracking/) — three phone-size proposals with three game situations. A + C is selected: heart counts beside the cards and moon status above the hand.

[Read the portfolio case study](portfolio/accessible-card-games.md) — Shawn's product decisions, the tradeoffs behind the selected designs, and the evidence supporting the current game.
